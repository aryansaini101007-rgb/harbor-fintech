# Harbor Finance

Official web platform for Harbor Finance — Education Loans for Studying Abroad & Student Forex Services.

## Tech Stack

- **Framework**: TanStack Start (SSR / Fullstack)
- **Routing**: TanStack Router
- **UI**: React 19, Tailwind CSS, Lucide React, Framer Motion
- **3D Visuals**: Three.js / React Three Fiber
- **Data Fetching**: TanStack React Query

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```sh
npm install
```

### Local Development

```sh
npm run dev
```

### Production Build

```sh
npm run build
npm run preview
```
